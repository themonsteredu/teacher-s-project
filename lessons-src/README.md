# 수업 모듈화 시범: 초2 AI 1차시 학생 퀴즈

기존 운영 주소와 사용 방식을 유지하면서 퀴즈 내용과 동작 코드를 분리한 첫 시범이다. 프로그램 등록, 반 코드, 자료 공유, 제출물 및 진로기록은 기존 허브 기능을 그대로 사용한다. 이 퀴즈의 결과는 지금처럼 기기에서 그림으로 저장되며 자동 제출되거나 진로기록에 연결되지 않는다.

| 구분 | 원본 또는 결과 | 수정할 때 |
|---|---|---|
| 수업별 퀴즈 내용 | `grade2-ai-01/questions.json` | 문항·이름·답·설명 수정 |
| 퀴즈 실행 기능 | `quiz-engine/student-quiz.js` | 퀴즈 화면 전환·점수·결과 이미지 등 공통 동작 수정 |
| 실행 HTML | `../public/lessons/초2-인공지능/1차시-학생용-AI퀴즈.html` | 생성된 스크립트 영역을 직접 고치지 않음. 화면과 디자인은 현재 이 파일에 유지 |

## 수정·검증

1. `questions.json`의 내용을 수정하거나, 퀴즈 실행 기능을 변경한다.
2. 저장소 루트에서 `npm run lesson:build`를 실행한다. 생성 영역의 스크립트만 갱신한다.
3. `npm run check`를 실행한다. 원본과 HTML이 다르면 검사에 실패한다.
4. 원본과 실행 HTML을 함께 커밋한다. Git으로 배포되는 사이트의 기존 주소는 변경되지 않는다.

실행 HTML은 CSS·폰트·자바스크립트를 포함한 단일 파일이므로 기존처럼 직접 열거나 업로드할 수 있다. 파일을 허브에 별도로 업로드한 복사본은 레포 배포만으로 자동 갱신되지 않는다. 해당 복사본이 실제로 사용 중이면 검증한 생성 HTML을 다시 업로드하거나 관리자가 저장소 경로를 연결해야 한다.

이 시범은 1차시 학생 퀴즈 하나에만 적용된다. 기존 교사용 교안과 다른 차시, 다른 웹앱, 데이터 구조는 아직 바꾸지 않는다. `quiz-engine`을 다른 수업에서 쓸 때에는 그 수업의 화면 구조와 결과 저장 방식이 같은지 먼저 확인한다. 이 기능을 수정하면 생성 대상 퀴즈의 동작이 영향을 받으므로 모든 대상의 재생성과 검증이 필요하다.
