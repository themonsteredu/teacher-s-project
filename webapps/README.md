# webapps — 교안·웹앱 원본 보관소

이 폴더는 허브에 올릴 **HTML 교안·웹앱의 원본을 보관**하는 곳입니다.
허브(사이트)는 "서비스하는 곳"일 뿐이고, **진짜 원본은 여기 있습니다.**
허브가 사라져도·DB가 날아가도 이 폴더의 파일은 그대로 남습니다.

## 워크플로우 (레포는 계속 1개, 파일만 쌓임)

```
①  만들기      →   ②  여기 저장        →   ③  허브에 업로드
   (HTML 1개)       webapps/ 폴더에         관리자 화면 → 프로그램 →
                    커밋해서 보관            첨부파일로 .html 업로드
```

- 개별 교안·웹앱마다 **레포를 새로 만들지 않습니다.** 파일만 이 폴더에 추가하면 끝.
- 허브에서 다시 빼내고 싶으면: 관리자 계정으로 다운로드(항상 가능). 하지만 여기 원본이 있으니 그럴 일도 별로 없음.
- 다른 학교·다른 사이트에서 쓰고 싶으면: 이 폴더의 파일을 그대로 복사·업로드·전달하면 됨.

## 폴더 구조

```
webapps/
  README.md          # 이 문서 (만드는 법 포함)
  _template.html     # 새로 만들 때 복사해서 쓰는 빈 뼈대
  examples/
    모둠뽑기.html      # 실제로 도는 예시 (참고용)
```

새 교안은 `_template.html`을 복사 → 이름 바꾸고 → 내용 채우면 됩니다.

# HTML 어떻게 만드나

## 지켜야 할 규칙 3가지 (허브가 웹앱으로 실행해주는 조건)

허브는 업로드된 `.html`을 새 탭에서 **진짜 웹앱처럼 바로 실행**해 줍니다.
단, 아래 3가지를 지켜야 제대로 열립니다. (`lib/api.js`의 `/open` 라우트 기준)

### 1. 파일 하나로 자기완결(self-contained)
별도 `.css` `.js` 이미지 파일을 **바깥에서 불러오면 안 됩니다.** 업로드는 파일 1개 단위예요.

| 항목 | 방법 |
|---|---|
| CSS | `<style>...</style>` 로 **HTML 안에** 직접 |
| JavaScript | `<script>...</script>` 로 **HTML 안에** 직접 |
| 이미지 | ① 인터넷 되는 곳이면 `https://` 주소로 링크 <br> ② 확실하게 넣으려면 **data URI**로 파일에 박아넣기 (아래 참고) |
| 외부 라이브러리 | `https://` CDN 링크만 가능 (예: `<script src="https://cdn.jsdelivr.net/...">`) |

❌ `<link href="style.css">`, `<script src="app.js">`, `<img src="cat.png">` → 전부 깨집니다.

### 2. 3.5MB 이하
3.5MB를 넘으면 웹앱으로 안 열리고 다운로드로 빠집니다.
이미지가 크면 data URI로 박지 말고 `https://` CDN 링크를 쓰세요.

### 3. 백엔드 없음 (브라우저 안에서만 도는 것)
서버·데이터베이스가 필요한 앱은 이 방식으로 못 올립니다.
- ✅ 되는 것: 퀴즈, 타이머, 랜덤 뽑기, 계산기, 카드 뒤집기, 시뮬레이션, 게임, 슬라이드, 활동지 뷰어 등 **브라우저만으로 도는 모든 것**
- ❌ 안 되는 것: 로그인/회원가입, 서버에 데이터 저장, DB 조회가 필요한 것 → 이런 건 따로 배포하고 허브엔 'aiapp' 링크로 등록

## 뼈대 (이대로 시작하면 됨)

```html
<!doctype html>
<html lang="ko">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>수업 제목</title>
  <style>
    /* 여기에 CSS를 직접 씁니다 */
    body { font-family: system-ui, sans-serif; margin: 0; padding: 24px; }
  </style>
</head>
<body>
  <!-- 여기에 화면 내용 -->
  <h1>안녕하세요</h1>

  <script>
    // 여기에 JavaScript를 직접 씁니다
  </script>
</body>
</html>
```

`<meta charset="utf-8">` 는 **꼭** 넣으세요. 없으면 한글이 깨집니다.
`<meta name="viewport" ...>` 는 태블릿·휴대폰에서 제대로 보이게 해줍니다.

## 자주 쓰는 패턴

**이미지를 파일에 박아넣기 (data URI)** — 인터넷 없이도 보이게:
```html
<img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUg...">
```
> 이미지를 base64로 바꾸려면 "이미지 base64 변환" 사이트를 쓰거나, 그냥 저(클로드)에게 "이 이미지 data URI로 박아줘"라고 하면 됩니다.

**외부 라이브러리 쓰기** — 예: 차트:
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```

**영상을 교안 안에서 자동 재생** — 파일을 안 고치고도 영상 교체:
허브에서 교안을 열면 `window.__LESSON_VIDEO__` 에 **'프로그램 편집 → 영상 링크'** 에 등록한
주소가 자동으로 들어옵니다. 교안은 이 값을 읽어 흐름 중간에서 재생하면 됩니다.
```js
const VIDEO_URL = (typeof window !== 'undefined' && window.__LESSON_VIDEO__) || '';
// VIDEO_URL 이 있으면 <iframe>/<video>로 재생 (템플릿의 '영상 자동 재생' 블록 참고)
```
> 이렇게 만들면 영상을 바꿀 때 **파일을 고치거나 재업로드할 필요가 없습니다.**
> 관리자 화면의 프로그램 편집에서 영상 링크만 바꾸면 교안에 즉시 반영됩니다.
> 뼈대는 `_template.html`의 "영상 자동 재생" 블록에 이미 들어 있습니다.

**입력값 임시 저장** — `localStorage` 사용 가능 (그 브라우저 안에서만 유지됨):
```js
localStorage.setItem('점수', 100);
```
> 단, 브라우저별로 따로 저장되고 서버엔 안 올라갑니다. 진짜 데이터 수합이 필요하면 허브의 **학생 활동 보드**를 쓰세요.

## 업로드 전 체크리스트

- [ ] `<meta charset="utf-8">` 있음 (한글 안 깨짐)
- [ ] CSS·JS가 전부 파일 안에 있음 (바깥 `.css`/`.js` 참조 없음)
- [ ] 이미지가 `https://` 또는 data URI (로컬 파일 경로 아님)
- [ ] 파일 크기 3.5MB 이하
- [ ] 파일을 브라우저로 직접 열어봐서 잘 도는지 확인 (더블클릭)

## 새로 만들고 싶을 때 제일 쉬운 방법

저(클로드)에게 이렇게 말하면 됩니다:
> "초등 3학년 곱셈 연습 웹앱 만들어줘. 자기완결 HTML로."

그러면 위 규칙을 지킨 파일 하나로 만들어 `webapps/`에 넣어드립니다.
당신은 그걸 허브에 업로드만 하면 끝.
