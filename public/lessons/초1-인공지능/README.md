# 초1 인공지능 1~5차시

기준: 사용자 제공 1학년 2학기 AI-L.E.A.P. 16차시 계획서의 1~5차시 인쇄 내용. 판독 불가능한 빨간 필기는 반영하지 않음.

## 작업 격리
- 기준 커밋: 90d5dad. 원격에서 확인된 초2 교사용 deck/topbar/board/spine/foot 양식을 계승.
- 이 폴더만 추가. 2학년·공통 헤더·진로기록·API·DB·허브 등록 변경 없음.
- 학교 헤더는 임시 독립 어댑터: `?school=학교명`. textContent로 렌더링하고 인쇄 직전에 반영. 학교 인증이나 테넌트 식별 용도가 아님.
- Claude의 학교별 헤더 계약이 완성되면 이 폴더의 school 읽기 부분만 연결. 보성초를 기본값으로 고정하지 않음.

## 실행
index.html에서 교사용/학생용 각각 실행. 교사용은 차시별 40분 진행안 포함. 모든 HTML은 폰트/CSS/JS 인라인으로 단독 업로드 가능. S-Core Dream 라이선스는 기존 public/fonts/LICENSE-S-CORE-DREAM.txt 참조.

## 낮춘 난이도
한 화면 한 질문, 말하기와 탭 선택, 점수·타이머 없음. 2차시는 네 종류 자료만 경험하고 동영상은 교사 구두 설명. 3차시 세 장면, 4차시 그림 한 장, 5차시 한 문장. 긴 정의나 자유 프롬프트 입력 없음.

## 수업 준비
실제 AI 스피커 또는 교사가 준비한 실제 사용 영상, 교실 자료·하루 그림카드, 태블릿/종이·색연필. 4차시 AutoDraw는 교사 시연 후 사용하며 내장 그림판은 AI가 아님. 외부 AI API 연결 없음.

## 저장
localStorage moakit:grade1:ai:v1. 4차시 그림→5차시 연결은 같은 출처/브라우저에서만 가능. 다른 기기는 PNG 저장/불러오기. 학생 식별·서버 전송·진로기록 자동 제출 없음. 공용 기기는 다른 학생 시작 버튼 사용.

## 인쇄
각 차시 활동지 인쇄 버튼, 브라우저 PDF 저장 가능. 학교명은 화면에서 변경 가능. 이름/반/번호는 종이에 기입. 3차시는 세 칸, 4~5차시는 저장된 그림 반영.
