# 수업 교안 (lessons)

차시별 수업 교안 HTML을 여기에 보관한다. **레포가 원본(source of truth)** 이고,
푸시하면 재배포와 함께 사이트에 자동 반영된다. (재업로드 불필요)

## 폴더·파일 이름 규칙

```
public/lessons/
  _shared/                    공통 디자인 틀 — 한 번 고치면 전 교안 반영
    base.css                  색·타이포·레이아웃 (화면 꽉 채움: 고정폭 금지)
    video.js                  주입/?video= 영상을 .videoframe에 삽입
  <학년>-<과목>/               예: 초2-인공지능
    <n>차시-<주제>.html         예: 1차시-인공지능이해.html
```

- 폴더: `초2-인공지능` (학년 + 과목/프로그램)
- 파일: `1차시-인공지능이해.html` (차시 + 주제)
- 사이트 링크 라벨: `1차시 · 인공지능이해` → 프로그램의 🎓 초2 와 합쳐져
  화면에 "초2 1차시 인공지능이해" 로 읽힘

## 새 교안 작성 규칙

1. `<head>` 에 공통 틀을 링크한다:
   ```html
   <link rel="stylesheet" href="../_shared/base.css">
   <script defer src="../_shared/video.js"></script>
   ```
2. **고정 폭(max-width:1020px 등) 금지.** `base.css`의 `clamp()`·`vw`가 어느 화면에서도
   꽉 차게 해준다. (2/3만 차던 문제의 원인이 고정 폭이었음)
3. 영상은 `<div class="videoframe" data-video></div>` 자리만 두면, 실제 영상은
   관리자가 프로그램 편집에서 링크만 바꿔 교체한다.

## 사이트 연동

프로그램 링크의 주소를 `/lessons/<학년-과목>/<차시>.html` 로 넣으면,
상세 화면에 **▶ 수업 실행(전체화면 발표)** + **⬇ 받기** 버튼으로 표시된다.

## 전체화면 발표(화면 꽉 채움)

▶ 수업 실행으로 열면 교안이 모니터 화면을 꽉 채운다(좌우 여백 없음, 다음/이전 버튼 항상 보임).
사이트가 발표 창에 다음 규칙으로 CSS를 넣어주기 때문이며, **교안 파일은 안 건드린다**
(학생 폰 화면·새 탭 보기는 그대로 예쁜 카드 유지):

- 선생님 슬라이드는 최상위 카드를 `.deck`, 하단 버튼줄을 `.foot`, 스크롤될 본문을 `.board` 로 둔다.
  → 화면을 꽉 채우고 상·하단 고정, 본문만 스크롤된다.
- 학생 앱은 최상위를 `.wrap` 으로 두면 배경이 화면 전체, 카드는 가운데 크게 배치된다.
- 위 구조가 아닌 교안을 화면 꽉 채우려면 `<html data-present="fill">` 를 준다.
