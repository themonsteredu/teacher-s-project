# 교안 HTML 작성 가이드 (Codex / 외부 도구용)

수업 슬라이드·학생 앱을 다른 AI(코덱스 등)로 만들어 이 사이트에 올릴 때,
**아래 구조 계약만 지키면 발표(전체화면)에서 안 깨진다.**
(화면 꽉 채움 · 좌우 여백 없음 · 다음/이전 버튼 항상 보임)

참고 뼈대(그대로 복사해 내용만 채우면 됨):
- 선생님 슬라이드 → `TEMPLATE-선생님슬라이드.html`
- 학생 활동 앱 → `TEMPLATE-학생앱.html`

---

## 절대 규칙 (안 지키면 깨짐)

1. **파일 하나로 자급자족(self-contained).** CSS·JS·폰트·이미지 전부 파일 안에 인라인.
   외부 링크(`<link href=…>`, `<script src=…>`, 웹폰트 URL, 원격 이미지) 금지.
   이미지는 `data:` URI 로 넣거나 이모지/인라인 SVG 사용.
2. **한 파일 3.5MB 이하** 권장(사이트 직접 업로드 시 이 크기까지 화면에서 바로 실행됨).
   폰트를 통째로 박으면 커지니 시스템 폰트 사용 권장.
3. **고정 픽셀 폭 금지.** `max-width:1020px` 같이 화면보다 좁게 고정하면 좌우에 빈 여백이 생긴다.
   크기는 `clamp()` · `vw` · `%` 로 잡는다.
4. `<meta charset="UTF-8">` 필수(한글 깨짐 방지). `<html lang="ko">`.

## 선생님 슬라이드 구조 계약

최상위를 `.deck` 로 두고, 그 **직계 자식**을 정확히 3개로:

```
<div class="deck">              (세로 flex 컬럼)
  <div class="topbar"> … </div>   상단 바 (고정)
  <div class="board">  … </div>   슬라이드 본문 (여기만 스크롤)
  <div class="foot">   … </div>   진행바 + 이전/다음 버튼 (고정)
</div>
```

- 슬라이드 한 장 = `.board` 안의 `<section class="slide">` 하나. 현재 장에만 `on` 클래스.
- 이전/다음 버튼은 반드시 `.foot` 안에. → 내용이 길어도 버튼은 안 잘림.
- 넘김 스크립트는 템플릿 것 그대로 재사용 가능.

## 학생 활동 앱 구조 계약

- 배경(그라데이션/색)은 **`body`** 에 준다. → 발표 때 화면 전체를 채움.
- 최상위 카드는 **`.wrap`** 하나. → 가운데에 크게 뜨고, 길어지면 카드 안에서만 스크롤(안 잘림).

## 그 외 자유 구조를 화면에 꽉 채우고 싶으면

위 `.deck`/`.wrap` 이 아니어도, `<html data-present="fill">` 를 주면
최상위 요소가 화면을 꽉 채운다. (단, 이땐 자체적으로 세로 스크롤을 처리해야 버튼이 안 잘림)

## 사이트 연동 시 선택 기능 (선택)

- **제목 한 곳 관리:** 제목 자리에 `data-title` 을 붙이면, 사이트 링크 라벨(`?title=`)이
  그 글자와 문서 제목을 자동 교체한다. (파일 안 고치고 사이트에서 제목만 바꿈)
- **영상 자리:** `<div class="videoframe" data-video></div>` 를 두면, 관리자가 사이트에서
  링크만 넣어 유튜브/영상을 꽂을 수 있다.

## 코덱스에 그대로 붙여넣을 프롬프트

> 아래 규칙을 지켜 **하나의 self-contained HTML 파일**로 수업 [슬라이드/학생앱]을 만들어줘.
> - 외부 리소스 금지: CSS·JS·폰트·이미지 전부 파일 안에 인라인. 이미지는 data: URI 나 이모지/인라인 SVG. `<link>`·외부 `<script src>`·웹폰트 URL 쓰지 마.
> - `<meta charset="UTF-8">`, `<html lang="ko">`. 한글 사용.
> - 고정 픽셀 폭(max-width:1020px 등) 금지. 크기는 clamp()·vw·% 로. 어느 화면에서도 꽉 차게.
> - [슬라이드일 때] 최상위 `<div class="deck">` 는 세로 flex 컬럼이고 직계 자식은 정확히 `.topbar`(상단 고정) / `.board`(본문, 여기만 overflow:auto) / `.foot`(진행바+이전/다음 버튼, 하단 고정) 3개. 슬라이드 한 장은 `.board` 안 `<section class="slide">`, 현재 장만 `on` 클래스. 이전/다음 버튼은 반드시 `.foot` 안에. 키보드 ←/→/스페이스로도 넘어가게 JS 포함.
> - [학생앱일 때] 배경색/그라데이션은 body 에. 최상위 카드는 `<div class="wrap">` 하나. 화면 전환은 section 을 hide/show.
> - 제목 요소엔 `data-title` 속성 추가. 영상이 필요하면 `<div class="videoframe" data-video></div>` 자리만 둬.
> 주제: (여기에 학년·차시·내용 적기, 예: "초3 2차시 – 데이터란 무엇일까, 슬라이드 8장")
